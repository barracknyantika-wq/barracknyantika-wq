### What I can build for you

- **Business websites and landing pages:** fast, mobile first, built with Astro or Next.js and tuned for search.
- **Booking and management systems:** admin dashboards, customer notifications and databases on Supabase.
- **Android apps:** web technology wrapped for Android with Capacitor, with live updates and a release pipeline.
- **Hosting and deployment:** VPS setup with CloudPanel, Cloudflare, SSL, caching, backups and uptime care.
- **SEO and Google Ads:** setup and tracking so the site brings in customers, not just visitors.
- **QA and testing:** I work as a QA analyst, so forms, payments, edge cases and devices get tested before your customers find the bugs.

### The security side

Most freelancers build and hope. I also break things on purpose, with permission, so attackers do not get the first look.

- Website and web app security audits: authentication, access control, input handling, exposed files and misconfigured headers.
- Penetration testing practice and ethical hacking on my own and authorised targets.
- Hardening for sites on a VPS or Cloudflare: firewall rules, bot and brute force protection, safe defaults.
- A clear written report you can act on, with fixes ranked by risk.

1. **Discover:** a short call or chat to agree on goals, pages and timeline.
